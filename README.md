# Проверка наличия в «Золотом Яблоке»

Загружает xlsx. Для каждого товара с листа «МНС Галерея» проверяет наличие в магазине goldapple.by
**пр-т Победителей, 9 (ТРЦ Galleria Minsk, магазин 180)** и выводит товары, которых нет или мало (3 шт. и меньше), в виде текста с номерами из первой колонки.

Проверка запускается закладкой (bookmarklet) на открытом goldapple.by. Иначе нельзя: сайт закрыт
анти-бот защитой и не отвечает на запросы с других сайтов.

## Публикация на GitHub Pages
1. Загрузите эту папку в репозиторий (`index.html`, `checker.js`, `vendor/`, `.nojekyll`).
2. Settings → Pages → Source: *Deploy from a branch*, ветка `main`, папка `/ (root)`.
3. Откройте `https://<логин>.github.io/<репозиторий>/` и следуйте инструкции на странице.

## Как это работает
- Запрос наличия: `GET /web/api/v1/retailstore/city/stores/stock?cityId=<Минск>&itemId=<SKU>`, тот же, что у кнопки «Наличие в магазинах».
- «Нет» — 0 шт., «Мало» — от 1 до 3 шт. (настройка `lowMax`).
- Сайт пропускает около 3 запросов в минуту, поэтому пауза между запросами 20 с. При ответе 403 проверка ждёт минуту и повторяет запрос.
- Прогресс сохраняется в браузере. После перезагрузки нажмите закладку и «Продолжить».
- Настройки (город, магазин, лист, порог «мало») находятся в начале `checker.js`, в объекте `CFG`.
