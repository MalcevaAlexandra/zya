# Отчёт по наличию

Веб-страница для iPhone, которая помогает быстро собрать отчёт о наличии товаров в магазине «Золотое яблоко» (бренды Гельтек и The U). Открывается в браузере, работает как приложение и ничего не устанавливает.

## Как это работает

1. Загрузить свой Excel со списком позиций (один раз).
2. Пройти по карточкам: открыть товар на сайте, посмотреть остаток и нажать **Много**, **Мало (3 шт и меньше)** или **Нет**.
3. На вкладке **Отчёт** нажать «Скопировать отчёт» и отправить текст.

Формат отчёта:

```
Отчет из магазина
Добрый день!
Магазин: минск, пр-т. Победителей, 9
Нет в наличии: 4, 15, 27
Мало (3 шт и меньше): 8, 19
```

В отчёт попадают номера из первой колонки таблицы, по возрастанию.

## Формат Excel

Первый лист, первая строка с заголовками. Колонки по порядку:

| Колонка | Что там |
|---|---|
| A. Номер | Номер позиции, он попадает в отчёт |
| B. Код товара поставщика | Для справки |
| C. SKU | Артикул товара с сайта |
| D. Название | Название позиции |
| E. Ссылка | Адрес страницы товара (необязательно) |

Колонку «Ссылка» можно не заполнять. Тогда на карточке появится поле для вставки ссылки: вставленный адрес сохранится и в следующий раз кнопка «Открыть товар» будет вести прямо на страницу.

## Вкладки

- **Проверка**: карточки позиций и три кнопки статуса. Есть «Назад», «Пропустить» и «К неотмеченным».
- **Список**: добавить, изменить или удалить позицию, загрузить Excel заново, скопировать весь список (вместе со ссылками) для вставки в Excel.
- **Отчёт**: готовый текст, число неотмеченных позиций, сброс для новой проверки.

## Установка на iPhone

Открыть страницу в Safari, нажать «Поделиться» и «На экран Домой». Так страница открывается как приложение, а сохранённый список надёжнее переживает очистку данных браузером.

## Где хранятся данные

Список, ссылки и отметки хранятся только в браузере на телефоне (localStorage) и никуда не отправляются. Если очистить данные Safari, список пропадёт. Поэтому храните исходный Excel и время от времени копируйте список кнопкой «Скопировать список (для Excel)».

## Обновление страницы

Заменить файл `index.html` в репозитории новой версией. Адрес страницы не меняется, список на телефоне остаётся.

## Ограничения

- Наличие страница сама не проверяет: остатки смотрит человек. Сайт показывает только «есть в наличии» без количества.
- Для чтения Excel нужен интернет (модуль SheetJS подгружается с cdnjs).
- Название магазина в отчёте задано в коде (`STORE` в `index.html`).
